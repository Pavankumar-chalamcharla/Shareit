⚠ Setup Required
This site needs to be configured before it works. Open index.html and fill in:
1. CLOUDINARY_CLOUD_NAME — your Cloudinary cloud name
2. CLOUDINARY_UPLOAD_PRESET — an unsigned upload preset
3. JSONBIN_BIN_ID — your JSONBin bin ID
4. JSONBIN_API_KEY — your JSONBin API key
5. ADMIN_PASSWORD — your secret delete password

See the README below for step-by-step setup instructions.
